## About

I've spent 7+ years building React and TypeScript applications, from PHI-regulated healthcare platforms to high-traffic retail e-commerce. My work sits where frontend architecture meets delivery: shared design systems that replace one-off components, performance budgets that hold up in production, and WCAG-aligned UI that ships with no release rollbacks.

- **Design systems at scale.** Expanded adoption of the Fondue design system to **12 applications** through shared libraries and config-driven UI patterns (Centene).
- **Release stability.** Kept **12+ React + TypeScript codebases** production-stable with **zero rollbacks** by coordinating cross-repo releases and dependency alignment.
- **Performance.** Cut page-load time **25%** with route-level code splitting, lazy loading and parallelized API requests (Siemens).
- **Quality and security.** Raised test coverage from **50% to 80%** and cleared **30+ SonarQube findings** protecting PHI/PII in shared frontend libraries.
- **Zero-to-one.** Grew an independent product from **0 to 50K monthly visits** through an SEO-first build.
